# 云图工作台实施方案

用户已批准：默认 Cloudflare 地址；员工账号可按实际人数新增，不限制为 4 个；按最多 4 名运营同时上传、每人 5 并发设计；统一账号管理；按照 outputs/图床UI方案 的六张浅蓝白设计实现全部页面。

架构：Electron Windows 客户端与 React/Vite 界面；Cloudflare Worker 托管 API 和网页管理界面；D1 保存员工、业务账号、权限、任务、文件、会话与上传租约；R2 直传，Worker 只签发短期授权并确认 HEAD，公开图片通过 Worker /img/:fileId 流式返回。独立生产桶保留 7 天。采用 D1 单语句原子租约，默认全局 20、每员工/设备 5，同一员工在多台电脑仍共享 5。预签名地址仅供受控客户端协调，非 R2 网络层硬限速。取消任务中止请求、释放名额，崩溃后租约超时回收。

安全：服务端验证所有权限；业务账号与员工登录分离；口令 PBKDF2，随机会话令牌仅存 SHA256；管理员首次引导设置口令，不公开默认密码；R2 密钥经 Worker secret 加密后保存在数据库，响应不返回密钥；存储未配置时明确阻止上传，不伪造成功。文件名不得注入 HTML/Excel 公式。公开链接使用不可猜测 ID；只允许已确认成功且未过期图片。禁用员工立即失效。日常软件不包含 R2 长期密钥。

## API 契约（响应 JSON；错误 {error:string}）
所有 /api 请求除 health/setup/login 外使用 Authorization: Bearer token 与 X-Device-Id；api.ts 自动附加。Electron 从 window.desktop 获取服务地址。网页同源。时间为 ISO UTC，界面本地显示。

GET /api/health -> {ok:true,initialized:boolean,storageReady:boolean,limits:{global:20,perDevice:5,perUser:5},version:string}
POST /api/setup {setupToken,username,password,displayName} -> 登录响应，仅无用户时可用。
POST /api/login {username,password,deviceId} -> {token,user:{id,username,displayName,role,status,mustChangePassword},groups:Group[]}
GET /api/me -> {user,groups}; POST /api/logout {}; POST /api/password {oldPassword,newPassword}
GET /api/groups -> {groups:[{id,name,status,permissions:{upload,view,export,delete},todayBytes,onlineDevices}]}
POST /api/groups {name}; PATCH /api/groups/:id {name?,status?}
GET /api/users -> {users:[{id,username,displayName,role,status,groupIds:string[],permissions:{upload,view,export,delete}}]}
POST /api/users {username,displayName,password,role,groupIds,permissions}; PATCH /api/users/:id 同上可选；管理员管理，禁止禁用最后管理员。
GET /api/settings -> {settings:{retries:3,scanSubfolders:true,checkDuplicates:true,notify:true,exportFormat:'xlsx',sort:'name',retentionDays:7,perDevice:5,global:20},storage:{ready,endpoint,bucket,publicBaseUrl}}，不返回密钥。
PATCH /api/settings {settings}; POST /api/storage {accessKeyId,secretAccessKey,endpoint,bucket}（仅管理员；endpoint/bucket 必须等于部署配置）; POST /api/storage/test {} -> {ok,message}
POST /api/tasks {groupId,name} -> {task:{id,...}}
POST /api/tasks/:id/files {files:[{clientId,name,relativePath,size,contentType,sha256}]} -> {files:[{id,clientId,...}]}，每批最多100，单图最大50MB。
GET /api/tasks?groupId=&search=&status=&days=7&page=1 -> {tasks:[{id,name,groupId,groupName,total,success,failed,bytes,status,createdAt,durationMs}],total}
GET /api/tasks/:id -> {task,files:File[]}
POST /api/files/:id/lease {} -> {leaseId,uploadUrl,headers,expiresAt}，无空位429+Retry-After；未配置503。
POST /api/files/:id/complete {leaseId} -> {file}，R2 HEAD 核对大小后才成功。
POST /api/files/:id/fail {leaseId,error} -> {ok}；POST /api/files/:id/release {leaseId} -> {ok}。
GET /api/files?groupId=&search=&status=&page=1 -> {files:File[],total}
File={id,taskId,groupId,name,relativePath,size,contentType,status:'pending'|'uploading'|'success'|'failed'|'expired'|'deleted',error?,createdAt,expiresAt,url}
POST /api/files/delete {ids:string[]} -> {deleted:number}；删除需权限且回收对象，记录删除状态。
GET /api/export?taskId= 或 groupId= -> {files:[{name,relativePath,url,size,createdAt}]}，只成功、未过期、有导出权限的文件。
GET /img/:id -> stream R2 object，只成功且未过期，Content-Type image/*，不要求登录。
GET /api/audit -> {events:[]} 管理员审计。

## 验收
四个独立员工/设备各拿满5个租约，第6个被拒；总20时第21个被拒；回收后可继续。禁用和跨组访问被拒。失败文件不得进入导出。传图以真实授权目录小批次测试，不重复全量上传。没有密钥或部署权限时明确交付尚未启用项与本地可运行结果。
