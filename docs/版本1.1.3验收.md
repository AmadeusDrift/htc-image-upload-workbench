# 1.1.3 四账号入口

用户明确选择“拿到安装包就能直接选择账号进入”，并于 2026-11-05 明确授权将免密码运营入口部署到生产。

## 使用流程

- 默认入口显示 alpha、beta、gamma、delta 四张卡片，无运营密码输入框；点击直接进入。
- 展示各账号在线电脑数及当前占用上传授权，约每10秒刷新；心跳15秒、在线统计45秒窗口。已有授权仍单独按其有效期计入上传占用。
- 多台电脑可以进入同一账号，继续使用公司20路动态并发。
- 管理员使用独立密码入口；新入口只允许四个已启用的 employee 身份，沿用已有权限。
- 按账号保存本机未完成队列。切换到另一个账号再返回，可以恢复原任务ID、已成功图片和待传尾部；主检查点文件名、应用身份和原schema保持兼容。

## 访问方式和维护

`OPERATOR_CARD_ENTRY_ENABLED=true` 是显式上线配置。启用后，知道服务地址的客户端也可直接选这四个运营身份；不将它描述为只对已安装客户端保密。管理员、其他用户名、停用账号不能通过该入口进入。

公开状态只投影账号名称、可用状态和占用数字，不返回密码、哈希、令牌或权限内容。进入操作按设备/IP限速。原密码登录API保留兼容旧版本。

## 验证

- 33个测试文件、292项测试通过；前后端类型检查、构建与安装包校验通过。
- 本地实际Electron渲染1440×940和1080×720，四卡片无密码输入；点击进入、管理员入口、切换返回通过。截图使用本地模拟状态，不代表实际在线人数。
- 包内运行测试确认20个原生上传槽、Excel与图像依赖及按账号检查点恢复。
- 独立审查未发现权限边界和队列切换的阻断问题。
- 线上四账号直接进入、原身份保持、管理员接口拒绝、心跳及离开状态验证通过，诊断会话已退出。
- 原有正在上传的任务在后端切换后继续成功完成图片；不撤销既有上传授权。

本版补齐账号入口，未修复尚待样表确认的Excel导出完整性问题。
